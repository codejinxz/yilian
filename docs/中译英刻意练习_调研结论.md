# 中译英刻意练习：教学法证据 → 产品功能

## 结论先行
1. 有效机制是「产出 → 注意差距 → 重写」，不是「看答案」。中译英的独特价值是逼学习者做 L1→L2 句法重组（输出假说 + 注意假说）。
2. 证据最硬：聚焦式纠错 + 二稿、语块教学、形成性评价。回译/视译只有小样本准实验，属「初步证据」。刻意练习解释力有限（教育领域仅约 4% 方差），起效靠「具体目标 + 即时反馈 + 略超难度」。
3. 胜负手不是批改更细，而是**批改后必须重写，并把错误变成下一轮练习**。

## 一、有效 vs 低效
**较有证据**：① 聚焦式纠错 + 二稿（元分析对语法准确性有中等正效应；全面纠错收益递减）；② 对比批改/母语者改写（reformulation，显著增加 noticing）；③ 语块教学（干预研究总体正向，须「注意 + 复现」）；④ 形成性评价与透明 rubric（效应量 0.4–0.7，但 rubric 主要提升一致性，学习收益取决于是否用于自评与修改）。

**初步证据（样本小、常无对照）**：回译（n=21 准实验，词汇保持/写作/语法均改善）；视译（提升意群切分与阅读速度，对产出只是间接证据）；对比分析 + 翻译记词（Laufer & Girsai 优于纯语义加工）。

**常见但低效**：只看范文不重写；逐字对译、唯一答案；无限维度全错纠正；选择题/词义匹配当主力（识别 ≠ 产出）；背模板与单词表；无反馈的批量泛译。

## 二、好批改的六件事 + rubric 草案
好批改 = 判分 + 证据（引原句）+ 归因（错误类型）+ 最小修改 + 升级版 + 下一步练什么。只给总分等于没批。

100 分，5 维，每维 1–5 档：

| 维度 | 权重 | 判定标准 |
|---|---|---|
| 信息完整准确 | 30 | 无错译、漏译；因果、让步、指代等逻辑关系保留。增删信息须有理由。 |
| 语法准确 | 20 | 时态、冠词、主谓一致、单复数、介词；按每百词错误密度扣，不数个数。 |
| 搭配与用词 | 20 | 动名/介词搭配正确、词义韵相符；无中式搭配（如 learn knowledge）。 |
| 句法与重组 | 20 | 能拆流水句、选对主语、用主从与非谓语；不是中文语序逐句搬运。 |
| 语域与简洁 | 10 | 正式度与术语得当；删范畴词、冗余名词化、弱动词（make/do/have）。 |

考试映射：专八「忠实 60 / 语言适切 40」≈ 维度 1+2 与 3+4+5；CATTI 用「错译漏译 + 流畅 + 语法」扣分制；雅思 TR/CC/LR/GRA 各 25%，另出换算表。

Prompt 约束：输出 JSON，每维给 score、evidence（原句片段）、error_tag（限 8–10 类）、minimal_fix、upgrade、next_drill；禁止只给总分，禁止改写超出原意。

## 三、7 个功能

| 功能 | 教学法 | 交互 | 优先级 | 成本 | 风险 |
|---|---|---|---|---|---|
| 二稿强制重写 | 形成性评价/纠错 | 按标签改≥3 处才能提交，自动 diff 一稿二稿 | P0 | 低 | 嫌慢；限 3 处并给进度感 |
| 三版对照 diff | 对比批改 | 我的句/最小修改/母语者改写，高亮并解释「为什么」 | P0 | 中 | 被当唯一答案；标注「多种可接受」 |
| 错误画像 | 错误分析 | 10 类标签聚合，周报看错误密度与类型迁移 | P0 | 中 | LLM 误标；可申诉 + 抽检 |
| 中式英语探测器 | 语块/对比分析 | 识别范畴词冗余、弱动词、名词化、流水句，给「删/换动词/拆句」微练 | P1 | 中 | 过度纠正可接受变体 |
| 回译闭环 | 回译 | 看目标英文→回译中文→与原文对齐 diff，标丢失/添加 | P1 | 中 | 链路长；每天限 1 句 |
| 语块产出卡 | 语块教学 | 从填空升级为「给语境写语块」，错则入 SRS | P0 | 低 | 模板化；需变式 |
| 考试模式 | 评分标准对齐 | 专八/CATTI/雅思三套 rubric + 限时 + 段级评分 | P1 | 中 | 被当押题；注明「诊断非预测分」 |

可选第 8：60 秒视译，P2、成本低，但与笔试目标易错位。

## 四、最不该做的三件事
1. **把「一键润色/直接给范文」当主反馈**：剥夺产出与 noticing，用户看得懂却写不出。
2. **唯一答案判死，或用相似度/BLEU 打分**：奖励直译与回避，惩罚合理意译。
3. **全维度全错纠正、只给总分**：信息过载、动机下降；证据支持的是少量、聚焦、可执行。
