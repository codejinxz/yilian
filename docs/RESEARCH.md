# 设计决策

## 核心判断

1. **胜负手是批改可信度 × 单题难度匹配**，不是题库大小。
2. **有效学习机制是「产出 → 注意差距 → 重写」**，不是看范文。
3. **本地优先**：能本地判定的不调模型，模型只做增强，失败必须降级。
4. **只调整今天的派单，不改用户数据**：降载、顺延、补做都必须可见、可撤销、有理由。

## 练习与反馈

| 决策 | 说明 |
|---|---|
| 语块级挖空 | 一句挖 1–3 个语块，不挖单个单词 |
| 可接受答案集 | 每空存 2–3 个合法译法，避免误杀 |
| 差异定位 | 错槽划线 + 正确答案 + 页边批注，不整句重写 |
| 阶梯提示 | 一次点一下：首字母 → 词数 → 答案 |
| 改对才过 | 答错必须重打参考译文，或显式选择「看答案，记为学习中」 |
| 溯源与申诉 | 每条批注挂考点标签；「不认同」可排除该条错题 |
| 首败处理 | 说明「还差几处」，不堆全部错误 |
| 下一步练什么 | 按错题考点直接跳到同考点下一句 |
| 评分标准 | 专八 / CATTI / 雅思三套映射，仅作参考，不作为预测分 |

五维评分（100 分）：信息完整 30 / 语法 20 / 搭配用词 20 / 句法重组 20 / 语域简洁 10。

模型输出必须包含：`score / evidence / error_tag / minimal_fix / upgrade / next_drill`。

## 复习与留存

| 决策 | 说明 |
|---|---|
| 三档复习 | 新题 / 复习中 / 已掌握；答错次日，答对 1→3→7→14 天 |
| 积压熔断 | 到期超过阈值进入降载，只推 5 道，其余顺延；顺延有上限 |
| 今日启动台 | 打开先看到期数与目标，一次点击进第一题，不做仪表盘 |
| 每日目标 | 默认 1 句，可设 1/3/5；完成即停，不再追问 |
| 连续天数可修复 | 中断不清零，每月两次「补做恢复」 |
| 会话边界 | 「今天到此」给复盘卡：练了几句、正确率、最该补什么 |

通知只对已安装用户开放，默认关闭，每天最多一条。

## 内容与管理

| 决策 | 说明 |
|---|---|
| 单人后台四件事 | 找到人、停用人、导题目、看趋势 |
| 原文默认不可见 | 查看答题原文必须选原因并写审计，不批量导出 |
| 删除一律软删 | 题库与题目进回收站，答题记录不删除 |
| 导入先校验 | `chunks` 拼接必须等于 `ref`；精确指纹硬拦、近似相似度提示 |
| 批次可回滚 | 每次导入生成批次，回滚进回收站 |
| 难度双轨 | 声明等级（四级/专八等）与计算难度并存，不互相替代 |
| 定级不贴标签 | 只说「先从哪档开始，N 题后自动校准」 |

## 模型与 Prompt

| 决策 | 说明 |
|---|---|
| 配置存库 | 供应商、模型、Key、预算都在后台改，保存即热更新 |
| 任务路由 | 填空批改走本地规则；整句、申诉、改写分别选模型 |
| Prompt 注册表 | 模板版本化，绑定任务，发布前跑回归集 |
| 调用账本 | 记录 trace、Prompt 版本、模型快照、token、成本、耗时 |
| 注入防护 | 用户答案定界为数据，不拼进 system；输出强校验 |
| 余额 | 能查的自动查，查不到显示估算消耗并允许手动录入 |
| 预算 | 80% 提醒，100% 自动降级本地批改，不静默扣费 |

## 数据与权限

- `attempts` 原文保留 90 天，聚合统计长期，审计 1 年。
- 判分 append-only：记录 normalizer / rubric / prompt / model 版本；改判写新记录。
- `/api/admin/**` 服务端统一鉴权，前端隐藏不算权限。
- 管理员不能停用或降级自己，不能移除最后一个管理员。
- 用户可自助导出 JSON；删号软删 30 天后匿名化。
- 时区：全 UTC 存储，按用户 IANA 时区计算日界。

## 暂缓

| 功能 | 原因 |
|---|---|
| 三版对照 diff | 依赖模型生成最小修改，先把单机闭环跑通 |
| 回译闭环 | 第三种练习模式，需要独立界面与判定 |
| 中式英语探测器 | 需要四层规则库 |
| 错句换皮回炉 | 变体质量不可控 |
| 个人语料导入 | 先做管理员导入 |
| 考试模式 | 限时与段级评分另做 |
| 周报与里程碑 | 需要至少两周真实数据 |
| 后台 2FA 与独立子域 | 公网部署前必须补 |

## 不做

- 排行榜、XP、抽奖、限时 FOMO
- 单一标准答案 + 字符串比对
- 无上限复习队列与无限题海
- 「以该用户身份登录」、无审计批量浏览原文
- 实时监控大屏
- 惩罚性连续天数
- 自由对话 AI 外教
- 开放 UGC 题库

## 2026-10-24 增补：游客真实可用与三题定级（前端先行）

- 游客真实可用 = 匿名拉公开题库（后端补 banks 只读端点，PUBLIC_OR_USER）+ 前端本地练习引擎（判分/排程/统计/降载，记录只存本机）；服务端零游客态，符合 D-001「游客只落本地」。
- 登录用户在服务端练习切片（#8）落地前同样走本地引擎；#8 落地后按适配层开关切回服务端，本地数据经 guest-upgrade 迁移（M2 契约已定）。
- 三题定级：首次打开进入、可整体跳过、设置页可重新定级；结果只说起点与「10 题后自动校准」，不贴等级标签（契约 §2.8）；状态只存本地，R-06「不建表不写 API」维持。
- 管理端九页签本轮按原型还原 UI，数据走 mock 演示层并注明；`/api/admin/**` 服务端鉴权红线不变。
- 命名决策（2026-10-24 追加）：上传/导入功能**保留 `upload` 命名**（后端模块 `upload`、页面 UploadPage、路由 `/admin/uploads`），不再改名为 imports；数据表现名 `import_batches` / `import_batch_rows`（V6 迁移），表名是否回改留待后端切片定夺，代码与文档自此不再引入 `imports` 模块名。
- PWA 边界决策（2026-10-24 追加）：Service Worker 只缓存带内容 hash 的静态资源（cache-first），导航（HTML）与 `/api/` 一律 network-only、不伪造响应——已安装用户**离线冷启动**会看到浏览器离线页；「本地优先」的离线能力指**页面已打开后断网**（离线横幅 + 草稿 + 离线队列 + 本地引擎续练）。若未来要「离线可开壳」，需缓存应用壳并补决策记录。
