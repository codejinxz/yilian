# 译练模型服务与数据出境说明（起草稿 v0.1 · 待运营者终审）

> 本文件是起草稿，尚未生效；须经运营者终审后方可作为发布口径，终审通过前不在任何前端页面呈现。
> 文中「运营者」指译练的运营方；文中标注「待确认」的条目如实反映当前状态，本说明不预设结论。

## 一、这份说明回答什么

1.1 当你使用答疑、模型复核、申诉初裁三类功能时，哪些数据会发给模型服务、用于什么目的、由谁处理，以及相关的数据出境口径。

1.2 本服务的主链路（练习、判分、复习调度、统计）不依赖模型服务；模型只做增强，调用失败自动降级，不会因此丢失你的练习数据。

1.3 本说明与《隐私政策》《用户协议》《年龄声明与未成年人保护》配套阅读；对同一事项口径不一致时，以对用户保护更严格的为准。

## 二、会发给模型服务的数据（逐项列）

2.1 答疑（你主动提问时）：

- 你输入的问题（有长度上限，当前 500 字）；
- 题目中文原句；
- 考点标签；
- 你自己最近一次批注的摘要。

不包含参考译文整体。回答固定附「AI 生成，可能有误」提示。

2.2 模型复核（你主动发起时）：

- 题目中文原句、参考译文、语块答案结构、你本人的提交与本地批注；
- 模型被要求输出限定结构的分数与理由（受限 JSON），不是自由对话；复核分作为该次提交的最新判分记录用于回看与统计（首判保留、复习排程与错题池维持首判口径）。

2.3 申诉初裁（你提交申诉后自动触发）：

- 被申诉批注的上下文与你的主张；
- 输出限定结构的初裁结论，仅供运营者人工终审参考；初裁不可用时落占位回执，不影响申诉提交。

2.4 除以上三类由你主动触发的功能外，你的其他数据不会发给模型服务。

## 三、不会发给模型服务的数据

除第 3.3 条说明的复核链路例外，以下数据永远不会发给模型服务：

3.1 你的密码（密码只以哈希存储，我们自己也不掌握明文）；

3.2 管理端模型服务密钥与其他系统密钥；

3.3 参考译文整体仅在模型复核链路发送（复核即重新判分）；答疑与申诉初裁不发送参考译文；

3.4 游客保存在本地浏览器的全部练习数据；

3.5 答疑问答历史（我们这边不落库，不存在后续发送）。

## 四、处理目的

4.1 模型服务收到的上述数据，仅用于：生成当前题目的答疑回答；生成复核分数与理由；生成申诉初裁结论。不用于广告、不向其他用户展示、不用于与本服务无关的用途。

4.2 模型服务商侧如何处理、是否保留这些数据，以其服务条款为准。服务商归属及其数据保留政策【待运营者确认】；确认前本条不预设结论，变更时更新本文。

## 五、服务商现状与变更机制

5.1 模型调用经运营者配置的模型服务网关转发（当前协议为 anthropic-messages）；当前模型为 GLM 系列。

5.2 服务商归属、所在地域与数据保留政策【待运营者确认】。本说明以运营者公布的当前配置为准；运营者变更服务商或模型时，会更新本文并在文末记录。

## 六、数据出境口径

6.1 本说明不预设当前服务商的注册地，不臆断其数据处理地域。

6.2 若运营者确认当前服务商在境内处理数据，则当前配置下你的相关数据在境内处理，不存在跨境传输。【待运营者确认后落定】

6.3 预留段：若未来切换到在境外处理数据的服务商，运营者将先更新本说明，并按照《中华人民共和国个人信息保护法》《中华人民共和国网络安全法》等法律法规的要求履行相应义务，然后才会实施变更。

## 七、你的可控手段

7.1 模型外发完全由你的主动行为触发：不开答疑、不点复核、不提交申诉，就没有任何数据发给模型服务。

7.2 若运营者未配置模型服务，三类功能整体不存在，同样零外发。

7.3 答疑功能可由运营者在管理端整体关闭；关闭后前端入口不再出现。

7.4 复核与申诉初裁都是单次请求，模型输出为限定结构的结果；答疑也是一问一答，不存在持续会话或后台自动调用。
