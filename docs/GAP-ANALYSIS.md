- 质量看板与人工抽检
- 灰度发布、影子流量、人审工作台
- 进步周报、语篇产出、考试模式、回译
- PWA 离线队列、更新提示、iOS 存储持久化
- 指标、告警、CI/CD

## 不做

- K8s / 微服务 / 多副本 / 分库分表
- 自研认证、加密、IDP、Prompt IDE、观测平台
- AI 批量造题自动发布
- 自动合并重复题
- 排行榜、惩罚性打卡、抽奖、AI 外教
- 开放 UGC 题库与社区
- 自建支付
- 无限题库与全科扩张

## 部署前必须确定

bootstrap 管理员策略：

| 环境 | 行为 |
|---|---|
| 本机 | 允许默认值，便于恢复 |
| 部署 | 默认值或未设置时启动失败 |
| 忘记密码 | 临时开启 `reset-password-on-startup=true`，用完关闭 |

## 原型与实现的边界

| 能力 | 原型 | 生产实现 |
|---|---|---|
| 判分 | 本地规则可跑 | 规则 + 可选模型 |
| 会话/限流/幂等 | 界面示意 | 服务端 |
| 备份/恢复 | 演练结果模拟 | 脚本 + 定期演练 |
| Prompt 版本/评测 | 版本展示 | 注册表 + 回归门禁 |
| PWA 离线 | 横幅模拟 | Service Worker + 队列 |
| 模型生成题库 | 固定样例 | 真实调用 + 计费 |
